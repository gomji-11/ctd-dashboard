CTD Dashboard v2.2.2 적용 안내

압축 안의 index.html, ctd.html, css, js 폴더를 기존 프로젝트의 같은 위치에 덮어씁니다.
GitHub Desktop에서 Commit 후 Push하고, 배포가 끝나면 브라우저에서 Ctrl + Shift + R로 새로고침합니다.

변경 사항
- 상단 카드 순서: 전체 품목 수 / 자사 품목 수 / 자사 CTD 전환 품목 수 / 위탁 CTD 품목 수 / 평균 필수 구비율
- 위탁 CTD 품목 수는 위탁 품목 중 CTD 전환 완료 품목만 집계
- CTD 관리 페이지에도 대시보드와 동일한 왼쪽 사이드바 유지
