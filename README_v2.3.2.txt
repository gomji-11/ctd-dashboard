CTD Dashboard v2.3.2 적용 방법

1. detail.html을 프로젝트 루트의 같은 파일에 덮어씁니다.
2. js/detail.js를 프로젝트의 js/detail.js에 덮어씁니다.
3. Commit 후 Push합니다.
4. 배포 완료 뒤 Ctrl + Shift + R로 새로고침합니다.

변경 내용
- 최신 CTD 구비현황은 기본적으로 조회 전용(잠금)입니다.
- 최신 개정이력의 '구비현황 수정'을 눌러야 편집할 수 있습니다.
- 수정 중인 개정번호와 경고 상태가 화면에 표시됩니다.
- '수정 종료 · 잠금'으로 즉시 다시 잠글 수 있습니다.
- 과거 개정은 구비현황을 수정할 수 없습니다.
- viewer는 계속 조회만 가능합니다.
