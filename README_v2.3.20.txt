CTD Dashboard v2.3.20 적용 안내

변경 내용
- CTD 개정이력의 '버전' 열을 'No.'로 변경했습니다.
- 개정이력은 등록 순서에 따라 1, 2, 3...으로 자동 표시됩니다.
- 개정이력 등록/수정 창에서 버전 입력란을 제거했습니다.
- 조회 상태, 삭제 확인, PDF 개정내역도 No. 기준으로 통일했습니다.
- 모듈별 최신본의 실제 문서 버전(v0.0, v0.1 등)은 기존대로 유지됩니다.
- 기존 Firebase 데이터 구조는 변경하지 않습니다.

적용 방법
1. 압축을 풉니다.
2. detail.html과 js/detail.js를 기존 프로젝트의 같은 위치에 덮어씁니다.
3. Commit 후 Push합니다.
4. 배포 완료 후 브라우저에서 Ctrl + Shift + R로 새로고침합니다.
