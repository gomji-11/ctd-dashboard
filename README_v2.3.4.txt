CTD Dashboard v2.3.4 적용 방법

1. index.html을 프로젝트 루트의 index.html에 덮어씁니다.
2. css/style.css를 프로젝트의 css/style.css에 덮어씁니다.
3. js/dashboard.js를 프로젝트의 js/dashboard.js에 덮어씁니다.
4. GitHub에서 Commit 후 Push합니다.
5. 배포 완료 뒤 Ctrl + Shift + R로 새로고침합니다.

변경 사항
- 관리자 모드, 비밀번호 변경, 로그아웃 버튼을 화면 오른쪽 위에 고정
- 품목 관리 바로가기와 상단 현황 카드가 고정 버튼에 겹치지 않도록 여백 분리
- 모바일에서는 버튼을 일반 배치로 전환해 화면 밖으로 잘리지 않게 처리
