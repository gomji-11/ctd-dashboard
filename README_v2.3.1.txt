CTD Dashboard v2.3.1 적용 방법

1. 압축을 풉니다.
2. detail.html을 프로젝트 루트의 같은 파일에 덮어씁니다.
3. js/detail.js를 프로젝트의 js/detail.js에 덮어씁니다.
4. GitHub Desktop에서 Commit 후 Push합니다.
5. 배포가 완료되면 Ctrl + Shift + R로 새로고침합니다.

주요 변경 사항
- 기존 CTD 구비현황을 개정번호 1로 자동 연결
- 새 개정번호 자동 제안(2, 3, 4...)
- 개정이력 저장 시 현재 CTD 항목 스냅샷 자동 연결
- 최신 개정 이후 모듈 변경 시 최신 개정 데이터 자동 갱신
- 과거 개정 스냅샷 보존
- 하단에는 최신 구비현황과 연결된 개정번호 표시

주의
- 최초 자동 개정번호 1은 admin 또는 editor가 해당 품목 상세 화면을 열 때 Firebase에 저장됩니다.
- viewer는 조회만 가능하며 데이터를 변경하지 않습니다.
