CTD Dashboard v2.3.16 적용 안내

수정 내용
- 모듈별 최신본 현황에서 시스템 개정번호 대신 CTD 항목에 입력한 버전을 표시합니다.
- 같은 모듈에 여러 버전이 있으면 개정일이 가장 최근인 항목을 우선 표시합니다.
- 개정일이 같거나 없으면 가장 높은 버전을 표시합니다.
- 입력된 버전이 없는 모듈은 '-'로 표시합니다.
- 버전 표시는 v0.1 형식(소수점 첫째 자리)으로 통일됩니다.

적용 방법
1. detail.html을 기존 detail.html에 덮어씁니다.
2. js/detail.js를 기존 js/detail.js에 덮어씁니다.
3. Commit 후 Push합니다.
4. 배포 완료 후 Ctrl + Shift + R로 새로고침합니다.

Firebase의 기존 데이터 구조는 변경하지 않습니다.
