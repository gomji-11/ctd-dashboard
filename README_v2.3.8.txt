CTD Dashboard v2.3.8 적용 안내

1. 압축을 풉니다.
2. detail.html을 프로젝트 루트의 같은 파일에 덮어씁니다.
3. js/detail.js를 프로젝트의 js 폴더에 덮어씁니다.
4. GitHub에서 Commit 후 Push합니다.
5. 배포 완료 후 Ctrl + Shift + R로 새로고침합니다.

변경 내용
- 개정이력 행 또는 '구비현황 보기' 버튼으로 개정 당시 저장본 조회
- 선택 중인 개정이력 행 강조
- 과거 개정은 조회 전용으로 잠금
- 최신 개정만 구비현황 수정 가능
- 바로 이전 개정과 값이 달라진 CTD 항목에 '변경' 표시

Firebase의 기존 품목 및 개정 데이터는 삭제하거나 변환하지 않습니다.
