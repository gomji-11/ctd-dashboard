CTD 관리시스템 v2.0.1

수정 내용
- CTD 관리 화면의 JavaScript 문법 오류 수정
- Firebase 품목 목록 구독 및 표 표시 정상화
- 자사 품목 / 위탁 품목 탭 전환 정상화
- 기존 제조구분 표기(자사제조, 자사 제조, 자사, 위탁제조, 위탁 품목 등) 호환
- 품목명 가나다순 정렬
- admin/editor는 추가·수정·삭제·백업 기능 사용 가능
- viewer는 읽기 전용 유지
- 품목 상세 화면의 돌아가기 링크를 CTD 관리 화면으로 변경
- CTD 항목 배열이 없는 품목도 목록 집계 중 오류가 나지 않도록 보완

데이터 관련
- Firebase products 컬렉션 구조를 변경하지 않았습니다.
- 기존 품목 및 CTD 세부 항목 데이터는 삭제하거나 이동하지 않습니다.

적용 방법
1. 이 압축파일을 풉니다.
2. 압축 안의 ctd-dashboard 폴더 내용을 현재 GitHub 프로젝트 폴더에 덮어씁니다.
3. GitHub Desktop에서 변경 파일을 확인합니다.
4. Summary에 "CTD 관리 v2.0.1 오류 수정"을 입력하고 Commit to main을 누릅니다.
5. Push origin을 누릅니다.
6. 배포 후 브라우저에서 Ctrl + Shift + R로 새로고침합니다.
