CTD Dashboard v2.1.0 적용 방법

1. 압축을 풉니다.
2. 압축 안의 index.html, css/style.css, js/dashboard.js를
   현재 ctd-dashboard 프로젝트 폴더의 같은 위치에 덮어씁니다.
3. GitHub Desktop에서 변경 파일 3개를 확인합니다.
4. Summary에 "대시보드 v2.1.0 UI 개편"을 입력합니다.
5. Commit to main → Push origin을 누릅니다.
6. 배포 완료 후 사이트에서 Ctrl + Shift + R로 새로고침합니다.

기존 Firebase 데이터 구조와 CTD 관리 화면 파일은 변경하지 않습니다.
