CTD Dashboard v2.3.11 적용 안내

변경 내용
- 개정이력 목록에 변경 모듈 요약 열을 추가하지 않음
- 개정이력 등록/수정 창에 실제 작성자 필수 입력란 추가
- 새 개정 생성 시 실제 작성자 이름 입력
- 로그인 역할명(admin/editor)이 작성자로 자동 저장되지 않도록 변경
- 기존 개정이력은 이력 수정에서 작성자 변경 가능
- 관리 열을 구비현황 보기 / 새 개정 생성 / 이력 수정으로 정리
- 삭제 버튼을 이력 수정 창 내부로 이동 (admin/editor 사용 가능)
- 최신 개정의 구비현황을 보고 있을 때만 구비현황 수정 버튼 표시
- 이전 개정과 실제로 달라진 항목에만 변경 배지 자동 표시
- 개정이력 목록에는 변경 모듈 요약을 표시하지 않음

적용 방법
1. detail.html을 프로젝트 루트의 같은 파일에 덮어씁니다.
2. js/detail.js를 프로젝트의 같은 위치에 덮어씁니다.
3. Commit 후 Push합니다.
4. 배포가 끝나면 Ctrl + Shift + R로 새로고침합니다.

Firebase의 기존 품목 및 개정이력 데이터는 삭제하지 않습니다.
