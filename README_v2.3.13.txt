CTD Dashboard v2.3.13 적용 안내

1. 압축을 풉니다.
2. detail.html 파일을 기존 detail.html에 덮어씁니다.
3. js/detail.js 파일을 기존 js/detail.js에 덮어씁니다.
4. GitHub에서 Commit 후 Push합니다.
5. 배포 완료 후 Ctrl + Shift + R로 새로고침합니다.

[추가 기능]
- CTD 구비현황 상단에 모듈별 최신본 현황을 추가했습니다.
- 18개 모듈을 요청한 순서대로 한 줄에 표시합니다.
- 각 칸은 해당 모듈이 마지막으로 변경된 개정번호를 자동 표시합니다.
- 최신 개정에서 변경된 모듈은 노란색으로 강조합니다.
- 등록된 코드가 없는 모듈은 '-'로 표시합니다.
- 가로 스크롤 없이 화면 폭 안에서 18칸이 보이도록 구성했습니다.
