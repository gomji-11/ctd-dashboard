CTD Dashboard v2.3.14 적용 안내

1. detail.html을 기존 detail.html에 덮어씁니다.
2. js/detail.js를 기존 js/detail.js에 덮어씁니다.
3. Commit 후 Push하고 배포 완료 뒤 Ctrl + Shift + R로 새로고침합니다.

변경 내용
- 버전 표기를 v0.1 형식으로 통일
- 모든 버전을 소수점 첫째 자리까지 표시
- Rev / Rev. 표기 제거
- 신규 개정 번호는 0.1씩 자동 증가
- 기존 숫자 및 Rev 형식 데이터도 v 형식으로 자동 표시
- 화면, 모듈별 최신본 현황, 확인창, PDF 보고서에 동일 형식 적용

기존 Firebase 데이터 구조는 변경하지 않습니다.
