CTD Dashboard v2.3.19 적용 안내

수정 내용
- 개정이력 관리 열에서 중복 기능인 '새 개정 생성'을 삭제했습니다.
- 새 개정이력은 상단의 '+ 개정이력 등록' 버튼으로 등록합니다.
- '구비현황 보기'와 '이력 수정' 기능은 그대로 유지됩니다.
- 모듈별 최신본 현황은 아래 CTD 목록에서 코드가 정확히 일치하는 행의 버전만 표시합니다.
- 시스템 개정번호와 같은 모듈의 하위 항목 버전은 사용하지 않습니다.
- 최초 버전 v0.0은 그대로 표시합니다.
- 버전 정보가 실제 빈칸인 경우에만 빈칸으로 표시합니다.
- 버전 표시는 v0.1 형식(소수점 첫째 자리)으로 통일됩니다.

적용 방법
1. detail.html을 기존 detail.html에 덮어씁니다.
2. js/detail.js를 기존 js/detail.js에 덮어씁니다.
3. Commit 후 Push합니다.
4. 배포 완료 후 Ctrl + Shift + R로 새로고침합니다.

Firebase의 기존 데이터 구조는 변경하지 않습니다.
